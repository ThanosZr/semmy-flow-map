# Χάρτης Ροών ΣΗΜΜΥ

Διαδραστικός χάρτης όλων των επιτρεπτών συνδυασμών ροών της ΣΗΜΜΥ ΕΜΠ για τα 23 μαθήματα εμβάθυνσης (6ο–9ο εξάμηνο), με πλάνο μαθημάτων για τον συνδυασμό που διαλέγεις.

- **Σφαίρα συνδυασμών**: κάθε σημείο είναι ένας συνδυασμός (κατεύθυνση + ροές), 239 συνολικά. Οι δέκα ροές είναι «άγκυρες» πάνω στη σφαίρα και κάθε συνδυασμός κάθεται στο κέντρο βάρους των ροών του (πλήρης = 1, μισή = ρυθμιζόμενο βάρος). Τα φίλτρα αριστερά σβήνουν ζωντανά όσα σημεία δεν ταιριάζουν, και κάθε επιλογή δείχνει πόσοι συνδυασμοί θα απομείνουν.
- **Σφαίρα μαθημάτων**: δίπλα, όλα τα μαθήματα 6ου–9ου εξαμήνου γύρω από την άγκυρα της ροής ή της κατηγορίας τους. Δείχνει τι είναι υποχρεωτικό, τι είναι στο πλάνο και τι μπορεί να μπει ως ελεύθερο για τον επιλεγμένο συνδυασμό (ή για όποιον δείχνεις με το ποντίκι). Κλικ σε μάθημα το προσθέτει ή το αφαιρεί από το πλάνο.
- **Πλάνο μαθημάτων**: τα υποχρεωτικά κάθε ροής, οι επιλογές «k από n», τα κατ’ επιλογήν, τα ελεύθερα, έλεγχος κανόνων (§7.5) και κατανομή ανά εξάμηνο.
- **Αρχείο**: εξαγωγή/φόρτωση όλων των επιλογών και ρυθμίσεων σε JSON, πρότυπο CSV για ECTS, αναφορά PDF (συνδυασμός, έλεγχοι, μαθήματα, εικόνες των δύο σφαιρών).
- **Ρυθμίσεις**: ανάλυση απόδοσης, MSAA, όριο fps, προτίμηση GPU, λεπτομέρεια γεωμετρίας, ένδειξη επιδόσεων, μέγεθος/ορατότητα σημείων, χρωματισμός, βάρος μισής ροής, απόσταση σημείων, έλξη προς Ο/Ι, δεύτερη σφαίρα on/off, αυτόματη εστίαση.

## Εκκίνηση

```bash
npm install
npm run dev            # τοπικός server με hot reload
npm test               # έλεγχοι κανόνων (πλήθος συνδυασμών, υποχρεωτικά, κανόνας iv, σφαίρα μαθημάτων, import/export)
npm run build          # dist/ για στατικό hosting (Three.js από CDN, ~46 kB gzip ο δικός μας κώδικας)
npm run build:offline  # ίδιο, αλλά με το Three.js μέσα στο bundle
```

Το `dist/` ανεβαίνει όπως είναι σε οποιονδήποτε static server. Οι διαδρομές είναι σχετικές, οπότε δουλεύει και σε υποφάκελο, όπως `https://<user>.github.io/semmy-flow-map/`. Η βιβλιοθήκη PDF και οι γραμματοσειρές της φορτώνονται μόνο όταν ζητηθεί αναφορά.

### GitHub Pages (demo)

Το `.github/workflows/deploy.yml` κάνει `npm ci`, `npm test`, `npm run build` και δημοσιεύει το `dist/` σε κάθε push στο `main`.

1. Ανέβασε το repo στο GitHub.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Κάνε ένα push (ή τρέξε το workflow από την καρτέλα Actions). Η σελίδα βγαίνει στο `https://<user>.github.io/<repo>/`.

### Cloudflare Pages (κύρια έκδοση)

Σύνδεσε το repo και βάλε:

| Ρύθμιση | Τιμή |
| --- | --- |
| Build command | `npm run build` (ή `npm run build:offline` για να μην εξαρτάται από CDN) |
| Build output directory | `dist` |
| Environment variable | `NODE_VERSION=20` |

## ECTS

Ο οδηγός σπουδών δίνει μόνο το σύνολο του διπλώματος (300 ECTS, §1.4), όχι ECTS ανά μάθημα. Γι’ αυτό:

- Αρχείο → **Πρότυπο ECTS** κατεβάζει όλα τα μαθήματα με κενή στήλη `ects`.
- Συμπληρώνεις τις τιμές (Excel/LibreOffice, διαχωριστικό `;`, δεκαδικό με κόμμα ή τελεία) και το φορτώνεις από Αρχείο → **Φόρτωση από αρχείο…**.
- Οι τιμές αποθηκεύονται στον browser, μπαίνουν στο JSON εξαγωγής και στο PDF, και το πλάνο δείχνει σύνολο ανά ροή και ανά εξάμηνο.
- Για μόνιμες τιμές σε όλους, συμπλήρωσε το `BUILTIN_ECTS` στο `src/data/ects.ts`.

## Απόδοση

- Κάθε σφαίρα σχεδιάζεται **μόνο όταν κάτι αλλάζει** (κίνηση κάμερας, μετάβαση φίλτρου, hover). Σε ηρεμία δεν τρέχει κανένα καρέ. Η γραμμή κατάστασης γράφει «αδράνεια».
- Παύση όταν είναι ανοιχτό το πλάνο, όταν η καρτέλα είναι κρυφή ή όταν μια σφαίρα βγει εκτός οθόνης. Η δεύτερη σφαίρα κλείνει εντελώς από τις ρυθμίσεις.
- Τα σημεία κάθε σφαίρας είναι **ένα** `THREE.Points` με δικό του shader. Οι μεταβάσεις (σβήσιμο, αλλαγή διάταξης) τρέχουν στη GPU μέσω uniforms.
- Λίγα draw calls ανά σφαίρα. Η ένδειξη επιδόσεων (Ρυθμίσεις) δείχνει fps, draw calls και μέγεθος buffer πάνω σε κάθε σφαίρα.
- Προεπιλογές: ανάλυση έως 2×, MSAA, όριο 60 fps, `powerPreference: low-power`, αυτόματη περιστροφή κλειστή.

## Ενημέρωση για νέο οδηγό σπουδών

1. Στο `src/data/catalog.ts` άλλαξε τις γραμμές μαθημάτων. Μορφή `κωδικός|όνομα` και `|‡` για μάθημα που δεν διδάσκεται.
2. Στο `src/data/rules.ts` έλεγξε τη `requirement()` (υποχρεωτικά πλήρους/μισής ροής) και τους κανόνες κατευθύνσεων.
3. Τρέξε `npm test`.
