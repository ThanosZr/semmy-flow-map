# Χάρτης Ροών ΣΗΜΜΥ

Διαδραστικός χάρτης όλων των επιτρεπτών συνδυασμών ροών της ΣΗΜΜΥ ΕΜΠ για τα 23 μαθήματα εμβάθυνσης (6ο–9ο εξάμηνο), με πλάνο μαθημάτων και ECTS για τον συνδυασμό που διαλέγεις.

- **Σφαίρα συνδυασμών**: κάθε σημείο είναι ένας συνδυασμός (κατεύθυνση + ροές), 239 συνολικά. Οι δέκα ροές είναι «άγκυρες» πάνω στη σφαίρα και κάθε συνδυασμός κάθεται στο κέντρο βάρους των ροών του. Τα φίλτρα (κατεύθυνση, σχήμα, ροές, εύρος ECTS) σβήνουν ζωντανά όσα σημεία δεν ταιριάζουν.
- **Σφαίρα μαθημάτων**: δίπλα, όλα τα μαθήματα 6ου–9ου εξαμήνου γύρω από τη ροή ή την κατηγορία τους: τι είναι υποχρεωτικό, τι είναι στο πλάνο, τι μπορεί να μπει ως ελεύθερο.
- **Πλάνο μαθημάτων**: υποχρεωτικά, επιλογές «k από n», κατ’ επιλογήν, ελεύθερα, έλεγχος κανόνων (§7.5), κατανομή ανά εξάμηνο και ECTS.
- **ECTS**: ανά μάθημα, ανά ροή, ανά εξάμηνο, σύνολο διπλώματος, και για κάθε συνδυασμό το εύρος (ελάχιστο–μέγιστο) των 23 μαθημάτων εμβάθυνσης. Χρωματισμός της σφαίρας κατά ECTS.
- **Κινητό και αφή**: πλωτό μενού με λειτουργίες Περιστροφή / Κύλιση σελίδας / Εξερεύνηση, κάρτες πληροφοριών με το δάχτυλο, οι δύο σφαίρες δίπλα-δίπλα με σύρσιμο, σύνοψη επιλογής με τον κανόνα κάτω από τη σφαίρα, λωρίδες στις άκρες για scroll.
- **Χρωματικά θέματα**: 6 έτοιμα (το αρχικό, πολύχρωμο, ηλιοβασίλεμα, δάσος, νέον, για αχρωματοψία), φωτεινό/σκούρο/αυτόματο, και επιλογή κάθε χρώματος ξεχωριστά. Ισχύουν και στο PDF.
- **Αρχείο και κοινοποίηση**: εξαγωγή/φόρτωση επιλογών και ρυθμίσεων (JSON), ECTS σε CSV για διόρθωση, αναφορά PDF με τις δύο σφαίρες, σύνδεσμο και QR, σύνδεσμος κοινοποίησης που ανοίγει το ίδιο πλάνο.

## Εκκίνηση

```bash
npm install
npm run dev            # τοπικός server με hot reload
npm test               # έλεγχοι: συνδυασμοί, υποχρεωτικά, κανόνας iv, ECTS, σύνδεσμοι, θέματα, import/export
npm run build          # dist/ για στατικό hosting (Three.js από CDN)
npm run build:offline  # ίδιο, αλλά με το Three.js μέσα στο bundle
```

Το `dist/` ανεβαίνει όπως είναι σε οποιονδήποτε static server. Οι διαδρομές είναι σχετικές, οπότε δουλεύει και σε υποφάκελο, όπως `https://<user>.github.io/semmy-flow-map/`. Η βιβλιοθήκη PDF, το QR και οι γραμματοσειρές φορτώνονται μόνο όταν ζητηθεί αναφορά.

Προαιρετικά, `VITE_PUBLIC_URL=https://…/` στο build ορίζει τη διεύθυνση που μπαίνει στους συνδέσμους κοινοποίησης και στο QR. Χωρίς αυτό χρησιμοποιείται η διεύθυνση της σελίδας. Μέσα σε iframe η κοινοποίηση κρύβεται, γιατί η διεύθυνση δεν θα άνοιγε για άλλους.

### GitHub Pages (demo)

Το `.github/workflows/deploy.yml` κάνει `npm ci`, `npm test`, `npm run build` και δημοσιεύει το `dist/` σε κάθε push στο `main`.

1. Ανέβασε το repo στο GitHub.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Κάνε ένα push (ή τρέξε το workflow από την καρτέλα Actions). Η σελίδα βγαίνει στο `https://<user>.github.io/<repo>/`.

### Cloudflare Pages (κύρια έκδοση)

Σύνδεσε το repo και βάλε:

| Ρύθμιση | Τιμή |
| --- | --- |
| Build command | `npm run build:offline` (ή `npm run build`) |
| Build output directory | `dist` |
| Environment variable | `NODE_VERSION=20` (προαιρετικά και `VITE_PUBLIC_URL`) |

## ECTS

- **Πηγή**: ο ελληνικός οδηγός δίνει μόνο το σύνολο (300 ECTS, §1.4). Οι τιμές ανά μάθημα είναι από τα αγγλικά προγράμματα σπουδών της σχολής:
  - [Undergraduate Curriculum 2020-21](https://www.ece.ntua.gr/media/630/Undergraduate_Curriculum_SchoolofECE_NTUA_2020_2021-20210220.pdf), για 168 από τα 177 μαθήματα,
  - [Undergraduate Curriculum 2018-19](https://www.ece.ntua.gr/media/628/Undergraduate_Curriculum_SchoolofECE_NTUA_2018_2019-20210220.pdf), με ίδιες τιμές για όλα τα κοινά μαθήματα (διασταύρωση).
- **Βεβαιότητα** (`src/data/ects.ts`, `confidenceOf`):
  - `confirmed`: ίδια τιμή και στα δύο προγράμματα,
  - `single`: μόνο στο 2020-21,
  - `moved`: το μάθημα άλλαξε εξάμηνο από τότε· εμφανίζεται με ≈,
  - `unknown`: 9 νεότερα μαθήματα (3400–3408), χωρίς τιμή.
- **Δίπλωμα**: 150 (1ο–5ο, 30 ανά εξάμηνο) + ό,τι δίνει το πλάνο 6ου–9ου + 30 (διπλωματική).
- **Εύρος ανά συνδυασμό** (`src/domain/ectsRange.ts`): το ελάχιστο και το μέγιστο που μπορεί να δώσει ένα έγκυρο πλάνο 23 μαθημάτων. Για κάθε όριο φτιάχνεται και ένα πραγματικό πλάνο, που οι έλεγχοι περνούν από τους ίδιους κανόνες με την εφαρμογή.
- **Δικές σου τιμές**: Αρχείο → **ECTS σε αρχείο** κατεβάζει όλα τα μαθήματα με τις τιμές και την πηγή τους. Αλλάζεις όσες θες και το φορτώνεις από Αρχείο → **Φόρτωση από αρχείο…**. Κρατιούνται μόνο όσες διαφέρουν από τις ενσωματωμένες.

## Απόδοση

- Κάθε σφαίρα σχεδιάζεται **μόνο όταν κάτι αλλάζει** (κίνηση κάμερας, μετάβαση φίλτρου, hover). Σε ηρεμία δεν τρέχει κανένα καρέ.
- Παύση όταν είναι ανοιχτό το πλάνο, όταν η καρτέλα είναι κρυφή ή όταν μια σφαίρα βγει εκτός οθόνης, και στο κινητό όταν η σφαίρα είναι στην άλλη «σελίδα».
- Τα σημεία κάθε σφαίρας είναι **ένα** `THREE.Points` με δικό του shader. Οι μεταβάσεις τρέχουν στη GPU μέσω uniforms.
- Προεπιλογές: ανάλυση έως 2× (1,5× σε κινητά), MSAA, όριο 60 fps, `powerPreference: low-power`, αυτόματη περιστροφή κλειστή.

## Ενημέρωση για νέο οδηγό σπουδών

1. Στο `src/data/catalog.ts` άλλαξε τις γραμμές μαθημάτων. Μορφή `κωδικός|όνομα` και `|‡` για μάθημα που δεν διδάσκεται.
2. Στο `src/data/rules.ts` έλεγξε τη `requirement()` (υποχρεωτικά πλήρους/μισής ροής) και τους κανόνες κατευθύνσεων.
3. Στο `src/data/ects.ts` πρόσθεσε ή διόρθωσε τιμές ECTS με την πηγή τους.
4. Τρέξε `npm test`.
